# ADA: Umbrella Laboratory

Unofficial Resident Evil fan game. Ada Wong and Albert Wesker rescue Leon Kennedy. Eight puzzles, six documents, Lady Dimitrescu boss fight.

Play: https://arinakhp.github.io/ada-umbrella/

Multiplayer rooms and progress are hosted in Supabase. No database secrets are included in this repository.

Controls: WASD/arrows to move, mouse to aim, click/space to shoot, E to interact, F to reload, 1/2 to select weapons, Shift to dodge.

Character artwork created with ImageGen. Resident Evil characters and trademarks belong to their respective owners. This project is an unofficial fan work.
